# 知行机器学习

> 边学边跑的中文机器学习实战教程。

面向有编程基础的学习者，以原创中文交互式笔记本（Notebook，Jupyter Notebook）逐步练习数据观察、建模与评估。课程主题参考吴恩达机器学习专项课程的公开大纲，讲解、实验和练习独立编写。试读数据均为本地生成的合成数据。

## 开始学习

按顺序完成这三节试读课程，每课预留 45—75 分钟，包含主动实验和练习：

1. [00｜进入笔记本](课程/00_起步与工具/00_进入笔记本.ipynb) — 熟悉单元运行、内核和可复现实验。
2. [01｜数组与向量运算](课程/00_起步与工具/01_数组与向量运算.ipynb) — 观察数组形状、广播、矩阵乘法，并批量计算手工预测。
3. [02｜数据与可视化](课程/00_起步与工具/02_数据与可视化.ipynb) — 画中文图表、划分数据、按训练统计填补缺失值，建立评估基线。

完整课程路线见 [AGENTS.md](AGENTS.md)。练习自检默认关闭；完成练习并填写答案后，可显式开启自检。提示和参考解放在可展开区域中。

## 本地运行

项目使用 Python 3.12 和 uv 管理依赖。先[安装 uv](https://docs.astral.sh/uv/getting-started/installation/)，在项目根目录执行：

```powershell
uv sync --locked --inexact
uv run --locked jupyter lab
```

同步命令按锁定文件安装项目依赖，并保留当前虚拟环境中的额外包。JupyterLab 是交互式笔记本工作台；启动后打开课程文件即可学习。

项目以 Python 3.12 为运行基线，uv 可自动下载并管理所需版本。首次准备环境需要联网下载依赖；准备完成后，三课实验均可在本地离线运行。

### 编辑器内核

- **PyCharm**：将项目解释器选为项目环境。Windows 使用 `.venv/Scripts/python.exe`；macOS 或 Linux 使用 `.venv/bin/python`。
- **JupyterLab**：右上角内核选择与项目环境对应的 Python 3 内核。

## 遇到问题

- 出现 `ModuleNotFoundError`：在项目根目录重新执行同步命令，再重启笔记本内核。
- 变量结果与预期不同：选择“重启内核并运行全部单元格”，让变量按文档顺序重新建立。
- 中文显示异常：安装系统中文字体后重启内核。Windows 可使用微软雅黑（Microsoft YaHei）；Linux 可使用 Noto Sans CJK SC 中文字体。第 02 课会自动从已安装字体中选择。

## 贡献者检查

项目提供笔记本检查脚本，可执行全本和折叠参考解的核对，默认不改源文件：

```powershell
uv run --locked python 教学工具/检查笔记本.py
```

使用 `--保存输出` 可更新审查后的教学输出；脚本会清理执行计数和机器相关元数据。提交前请检查文件差异及公开内容。
